# ADR 0002 – Gin as HTTP framework

- Status: accepted
- Date: 2026-10-26

## Context

We need a fast, widely known HTTP router with middleware support and request binding/validation.

## Decision

Use Gin. Controllers only bind input, call a usecase and render output; errors go through `c.Error` and a single error-handler middleware.

## Consequences

Large ecosystem and familiar to Go developers. Gin types must stay in `infra/rest`; usecases and domain never import Gin.
